As a Stage 1 analytical report &amp; predictive model for the USJ Stat Society Data Analysis Competition 'Data Xplore 2.0'. Developed a model using 9,722 patient records to predict stroke risk. Implemented data exploration, feature preparation, visualization, and insight generation to identify key clinical and lifestyle risk factors.
Background
Stroke remains one of the most critical global health challenges, contributing significantly to 
mortality and long-term disability. Early identification of individuals at high risk can enable timely 
intervention, reduce healthcare costs, and improve patient outcomes.
Modern healthcare systems collect large volumes of patient data, including demographic details, 
clinical measurements, and lifestyle information. However, extracting meaningful insights from 
this data to support decision-making remains a challenge.

Problem Statement
Using the available dataset, your task is to:
• Develop a model to predict the likelihood of a stroke event
• Identify the most influential factors contributing to stroke risk
• Generate insights that can support preventive healthcare strategies
Key Tasks
1. Data Understanding & Exploration
2. Data Preparation and Visualization
3. Model Development
4. Insight Generation
